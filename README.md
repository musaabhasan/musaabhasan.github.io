## GitHub Focus

The site and related repositories are intended to support open-source work in:

- information security governance and cyber risk
- business continuity and operational resilience
- digital transformation and learning technology in education
- applied AI and machine learning for security, learning, and operations
- IoT security, robotics lab hardening, and smart systems
- research companion material for cybersecurity, EdTech, and digital systems

## Featured Repositories

- [picarx](https://github.com/musaabhasan/picarx) - read-only security baseline checks and documentation for Raspberry Pi / PiCar-X style robotics labs.
- [tts-from-docx](https://github.com/musaabhasan/tts-from-docx) - Python workflow for converting Word documents into narrated audio for accessibility and learning-content use cases.
- [BlackboardQuizGenerator](https://github.com/musaabhasan/BlackboardQuizGenerator) - C# project for converting text-based questions into Blackboard LMS import formats.

## Repository Notes

This is a static HTML/CSS site. Changes to `index.html` and `styles.css` are published through GitHub Pages from the `main` branch.

For the GitHub profile README shown directly on [github.com/musaabhasan](https://github.com/musaabhasan), create a separate special repository named `musaabhasan` under the `musaabhasan` account and place the profile `README.md` in that repository.
